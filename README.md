# Forward Deployed Engineering Career Research

A concise, source-based research site about Forward Deployed Engineer (FDE) work, job requirements, and entry-level pathways.

## Run locally

```bash
npm install
npm run docs:dev
```

Open the local URL printed by VitePress.

## Build for production

```bash
npm run docs:build
npm run docs:preview
```

Research snapshot: November 12, 2026. Job listings change; always confirm details on the employer's official careers page.
