# Skills employers look for

This list groups requirements from the employer postings reviewed. It is a synthesis, not a claim that every employer requires every item.

## Technical skills

| Skill area | What it means in FDE work | Evidence in postings |
|---|---|---|
| Programming | Build, debug, and maintain working software | Google names Python or similar; OpenAI and Palantir emphasize hands-on engineering |
| Full-stack development | Build interfaces and backend services that solve a workflow | OpenAI FDSWE describes full-stack customer solutions |
| APIs and integration | Connect software to customer systems, data platforms, and services | OpenAI Healthcare and Google internship |
| Databases and data pipelines | Work with structured/unstructured data, relational databases, and vector databases | OpenAI FDSWE names Postgres/MySQL; Google names vector databases and RAG-like pipelines |
| AI application development | Build applications around models and agentic workflows | Google internship and OpenAI FDE roles |
| Cloud and infrastructure | Understand how software runs in customer environments | Google names cloud AI architecture; Palantir describes complex customer environments |
| Testing and evaluation | Measure system quality against defined requirements | Google names evaluation pipelines; OpenAI Healthcare names customer-specific evaluation and validation |
| Observability and reliability | Trace behavior, identify failures, and improve production systems | Google names observability; OpenAI roles emphasize reliability and production readiness |
| Security and governance | Respect access controls, privacy, and operational requirements | OpenAI Healthcare names PHI, HIPAA, authorization, governance, and auditability |

## Professional skills

- **Problem discovery:** Ask questions and understand the user's actual workflow before choosing a solution.
- **Clear communication:** Explain technical decisions to engineers, operators, and other stakeholders.
- **Adaptability:** Work when requirements are incomplete and change as new information appears.
- **Ownership:** Follow a solution from prototype through deployment and handoff.
- **Collaboration:** Work with customer teams and internal engineering, product, and research groups.
- **Documentation:** Record decisions, implementation details, and repeatable practices.
- **Judgment:** Balance scope, speed, quality, reliability, and the customer's constraints.

## Practical skill priorities for a student

1. Learn one general-purpose language well, such as Python or JavaScript.
2. Build web applications with a frontend, backend, and database.
3. Learn how to use and design REST APIs.
4. Practice Git, GitHub, testing, and debugging.
5. Deploy a project and write clear setup documentation.
6. Learn basic cloud concepts and how to connect an application to external services.
7. Add an AI feature only after the basic application works; test its output and document failure cases.
8. Practice explaining the problem, design choices, and trade-offs in plain language.

A strong portfolio project demonstrates a complete working solution and explains who it helps, how it works, how it was tested, and what you would improve next.
