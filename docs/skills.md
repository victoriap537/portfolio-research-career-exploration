# Skills employers look for

This list groups recurring requirements from the job postings reviewed. It is a synthesis, not a claim that every employer requires every item.

## Technical skills

| Skill area | What it means in FDE work | Evidence in postings |
|---|---|---|
| Programming | Build, debug, and maintain working software | OpenAI asks for production-grade backend/frontend code; Palantir lists several languages |
| Full-stack development | Build interfaces and backend services that solve a workflow | OpenAI FDSWE describes full-stack customer solutions |
| APIs and integration | Connect software to customer systems, data platforms, and services | OpenAI Healthcare and Google internship |
| Databases and data | Work with structured data, relational databases, and customer data systems | OpenAI FDSWE names PostgreSQL/MySQL |
| AI/LLM application development | Build applications around models and agentic workflows | OpenAI FDE and Google internship |
| Testing and evaluation | Measure system quality against defined requirements | OpenAI Healthcare and Google internship |
| Production engineering | Deploy, monitor, improve, and support reliable systems | OpenAI roles emphasize production deployment and adoption |
| Cloud and infrastructure | Understand how software runs in customer environments | Palantir and Google internship |

## Professional skills

- **Problem discovery:** Ask questions and understand the user's actual workflow before choosing a solution.
- **Clear communication:** Explain technical decisions to engineers, operators, and other stakeholders.
- **Adaptability:** Work when requirements are incomplete and change as new information appears.
- **Ownership:** Follow a solution from prototype through deployment and handoff.
- **Collaboration:** Work with customer teams and internal engineering, product, and research groups.
- **Documentation:** Record decisions, implementation details, and repeatable practices.

## Practical skill priorities for a student

1. Learn one general-purpose language well (Python or JavaScript).
2. Build web applications with a frontend, backend, and database.
3. Learn how to use and design REST APIs.
4. Practice Git, GitHub, testing, and debugging.
5. Deploy a project and write clear setup documentation.
6. Add an AI feature only after the basic application works; evaluate its output and failure cases.
7. Practice explaining the problem, design choices, and trade-offs in plain language.

A portfolio project should demonstrate a complete working solution and explain who it helps, how it works, and how it was tested.
