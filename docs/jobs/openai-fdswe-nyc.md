# OpenAI — Forward Deployed Software Engineer, NYC

<small>Employer posting reviewed November 12, 2026 · Full-time</small>

**[View the official OpenAI Careers posting](https://openai.com/careers/forward-deployed-software-engineer-nyc-new-york-city/)**

## Role summary

The Forward Deployed Software Engineer builds custom software using OpenAI's APIs to solve customer problems. The role works alongside customers and FDEs, then turns successful solutions into reusable abstractions that improve future delivery.

## Responsibilities in the posting

- Understand customer business challenges and technical requirements.
- Design, architect, and develop full-stack solutions iteratively.
- Scope proof-of-concept work and full production deployments.
- Work side-by-side with customer technical teams and code on their infrastructure.
- Collaborate with Product, Research, Applied teams, and customer-facing colleagues.
- Document best practices and share lessons from customer engagements.

## Experience and technical requirements listed

The posting asks for **7+ years of professional full-stack engineering experience**, excluding internships. It also names experience with relational databases such as PostgreSQL or MySQL. Customer-facing experience is desirable.

## What stands out

This posting emphasizes hands-on full-stack engineering and reusable software design. It shows how forward-deployed work can involve building abstractions that make later customer projects faster and more consistent.

## Relevance to a student

This is not an internship-level job description. The useful preparation areas are full-stack development, databases, API integration, iterative delivery, and building software that can be maintained and reused.
